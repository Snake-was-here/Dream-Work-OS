# Portfolio evidence

**Status: no verified entries yet.** Do not claim an example exists or insert an invented proof link. An opportunity may have “None verified” in Relevant Portfolio Work.

## Entry structure

Create one entry per owner-approved project, with a stable ID such as `P001`:

| Field | Required content |
|---|---|
| Project ID / title | Stable ID and real title |
| Link | Public demo/repository or approved shareable artifact |
| Problem | What the project actually addresses |
| Owner's contribution | Precise personal responsibility; distinguish collaborators |
| Technologies | Only reviewed or owner-confirmed technologies |
| Capabilities demonstrated | What a reviewer can reasonably observe |
| Results | Verified outcomes; otherwise “not measured” |
| Evidence / limitations | Supporting source, limitations, demo versus production |
| Approval | Owner-approved claims, date, and permission to share link |

Agents may inspect owner-provided projects and propose narrow claims, then ask the owner to confirm authorship/contribution and approve sharing. Never treat a project name or prior chat memory as sufficient proof. Never share private repository links or private artifacts without permission.
