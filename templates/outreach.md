# Outreach starting points

Adapt these to the real need and platform. Square-bracket text is a drafting instruction, never a verified fact. Remove unfillable claims; do not send placeholders.

## Relevant verified example
Hey [name] — saw you're looking for help with [specific problem]. I built [verified project and precise contribution], which seems relevant to [their concrete workflow].

[Approved proof link]

I could help with [small specific next step]. Are you still looking for someone?

## Transferable skill, no verified example
Hey [name] — saw your post about [specific need]. I work with AI agents, automation and product building, and this seems like a problem I could help with. I'd need to learn [specific gap] before committing to [scope].

Is the project still open, and what's the first workflow you want working?

## Employment
Hi [name], I'm interested in [role] because [specific problem the role addresses]. My [verified skill/evidence] is relevant to [responsibility]. [Honest gap where material.]

[Approved proof, if available.] I'd be glad to discuss [specific contribution]. [Answer required application questions only using confirmed facts.]
