# Outreach

Draft only for YES opportunities that are active enough to contact. Re-read the original need, requested route and full existing conversation first. Check for prior contact to the same company/person and avoid duplicate approaches.

## Draft checks
1. Identify the poster's concrete problem and the next useful action.
2. Select approved proof from PORTFOLIO.md. If none exists, write a modest self-reported skills statement or ask for proof; do not pretend a project exists.
3. State how the owner could help, with a narrow honest scope and visible relevant gaps.
4. Use the platform's natural tone: conversational Reddit reply, concise founder email, or slightly more formal application.
5. Keep it brief, usually 60–120 words, with one clear next step. Answer explicit application questions when verified facts permit.
6. Append a DRAFT message with the linked ID, destination, channel, subject if relevant, and notes identifying proof/claims used. Set opportunity DRAFTED and Next Action to human draft review.

Avoid “I hope this message finds you well”, generic compliments, inflated enthusiasm, buzzwords, reciting the listing and long introductions. Never claim prior client work, exact technologies, metrics or seniority without verified profile evidence. Explain transferable skill honestly rather than saying the owner has built an identical system.

## Sending gate

YES approves drafting. Sending requires explicit authorization identifying the message, recipient and channel (or a clearly scoped approved batch). If the draft changes materially after approval, obtain renewed authorization. Obey the poster's requested route and platform/community rules. If authorization or required identity/credentials is missing, preserve the finished draft and state exactly what is needed.

After confirmed send, update the message status/time and opportunity first-send timestamp, channel and next action. A failed attempt stays FAILED or DRAFT; do not set SENT without evidence. Never embed an auto-send action in a spreadsheet trigger.
