# Discovery

Search for **expressed demand**, not companies that might theoretically benefit from automation. Include both employment and paid contract/project work. Prefer a small verified batch over many stale leads.

## Search pass
1. Read profile, CONFIG preferences, rejected/blocked opportunities and recent outcomes.
2. Read live canonical URLs and dedupe keys before searching.
3. Search several source families from SOURCES.md using problems rather than only AI job titles.
4. Prioritize postings from the past 14 days; expand to 30 days or older active listings when useful. Record the actual date, never a search engine's approximate crawl date as a confirmed posting date.
5. Open the original post/listing and relevant replies. Verify availability, concrete need and permitted professional contact route.
6. Match and write only useful candidates with source evidence and explicit uncertainties. Record inaccessible candidates as UNCERTAIN; do not present them as verified.
7. Refresh existing matches without resetting decisions, statuses or message history. Report discoveries, updates and unresolved verification limits briefly.

## Problem query bank

Rotate these examples and learn from approvals:
- `"looking for" "workflow automation"`, `"need help" "internal tool"`
- `"hiring" "startup generalist"`, `"founding" "product engineer"`
- `"contract" "AI integration"`, `"freelancer" "MVP"`
- `"looking for" "research automation"`, `"agency" "subcontract" "automation"`
- `"need" "prototype"`, `"hiring" "websites"`, `"data collection" "contract"`

Use source filters, dates and variants of “build”, “fix”, “integrate”, “automate”, “replace manual” and “help”. Separate need evidence from speculative prospecting. Do not scrape restricted areas, bypass authentication/rate limits, or fabricate access.

## Optional recurring run

A scheduler may invoke this model-neutral task: “Read AGENTS.md and CONFIG. Discover and verify up to 5 recent employment or paid project opportunities across at least 2 source families, deduplicate and update the live sheet. Respect all human decisions. Draft only owner-approved YES opportunities when the verified profile is sufficient. Never send or submit. Stay quiet if there is no useful change; report new verified matches, blockers, or needed review.”

Suggested cadence: weekday mornings in the owner's confirmed time zone. Scheduling requires an actual configured scheduler; a repository prompt alone does not run searches. A failed run must not masquerade as zero market demand.
