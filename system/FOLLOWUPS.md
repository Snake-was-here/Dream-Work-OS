# Replies and follow-ups

Read all MESSAGES for an Opportunity ID in timestamp order, including drafts/superseded messages and send statuses. Read the opportunity and current profile. Do not reconstruct a conversation from the latest message alone.

## Inbound reply
1. Append a separate INBOUND message with actual known timestamp, channel, sender and content. Unknown dates remain unknown; note import time separately.
2. Record a Reply Outcome such as POSITIVE, NEUTRAL, NEGATIVE or UNKNOWN, grounded in the content. An automatic receipt is not a positive reply or interview.
3. Update Last Reply At. Set NEEDS RESPONSE if there is a question/action; otherwise REPLIED or the actual outcome state. Record positive/call/paid/accepted milestones only when confirmed.
4. Draft the next response in a new linked MESSAGES row. Answer using verified facts, preserve commitments and make unknowns visible. Human authorization is still required to send.

## Unanswered outreach

Default policy: one concise follow-up after 7 calendar days from the latest unanswered actual outbound message; a second only with explicit human approval. Respect a poster's timeline, platform rules and opt-outs. Use Next Follow-up At and each message's real send time; Sent At remains the first send. Inbound responses, rejection, CLOSED or DO NOT CONTACT cancel pending follow-ups. Never repeatedly reset the due date from a draft or sheet recalculation.

A follow-up should add a useful clarification, answer or small relevant example, then ask one short question. Do not use guilt, false urgency or “just bumping this” mechanically. A due date queues human review; it never sends automatically. Mark NO RESPONSE after the approved follow-up window expires, retaining all history. Confirmed paid trial/call details need accurate terms and scheduling; do not accept commitments on the owner's behalf without authorization.
